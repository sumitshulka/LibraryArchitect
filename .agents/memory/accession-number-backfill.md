---
name: Accession number backfill
description: Product decision about existing book copies when accession numbering is configured.
---

When an administrator enables accession numbering, assign numbers to current copies as well as future copies. Organization-wide numbering includes all current copies; library numbering includes copies already allocated to a library, while unallocated copies wait until allocation.

**Why:** the user chose to assign accession numbers to existing copies when asked.

**How to apply:** preserve this behavior when changing accession settings, acquisition, allocation, or copy imports.
